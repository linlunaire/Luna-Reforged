# 词缀目录

0.4.0 共 44 个词缀。每件装备同时保留一个词缀；重铸替换词缀并保留原名、附魔和耐久。数值说明由实际参数生成，所有内置词缀统一数值前置、增益绿色、代价红色。护甲按穿戴部位生效，多件减伤乘算。

烬火、霜凝、汲月只在有效伤害后触发，不能用无敌目标或被拒绝的命中刷效果。冷却由攻击者持有，换手、换武器或换目标都不能绕过。生命汲取以实际损失的生命与吸收生命计算；死亡前剩余生命限制了过量伤害可换得的治疗。点燃不会创建火焰方块，免疫火焰的目标不被点燃。

昼夜词缀只在有天空光照的维度生效；本模组夜间范围为时间 13000 至 23000 之前，昼间为其余时间。弓和投掷三叉戟保留发射时的武器词缀快照，射手状态及命中距离在命中时判断。

`includeNativeReforges: false` 关闭新抽取池中的全部 28 个原生扩展，保留原版 16 个及服主自定义词缀。已有装备保持有效。自定义字段见 [配置指南](custom-reforges.md)。

# 月色界面与效果设计

界面使用深靛色底纹、银色月牙与少量星光，给原生物品和文字留出空间。左侧完成重铸，右侧在没有石头时显示当前词缀，有石头时显示指定效果。状态、费用与按钮靠近输入槽；右侧截断的长说明可悬停查看全文。标题、状态和按钮均由游戏绘制，图片不包含文字。

## 0.5.0 词缀配色

渐变按字符着色，中文两字名称只会显示两个端点。因此端点需要各自清晰，并保持接近的亮度；仅更换插值算法不能改善两个字的明暗断层。潮汐旧起点 `#373B44` 接近深色面板，改为海青到水蓝。同类调整保持各词缀的水、引力和力量主题：

| 词缀 | 起点 | 终点 | 方向 |
| --- | --- | --- | --- |
| 潮汐 | `#68D6CE` | `#6EA8ED` | 海青到水蓝 |
| 引力 | `#8A9CE2` | `#B0BDEF` | 提亮靛蓝 |
| 强韧 | `#F08A84` | `#D46A76` | 珊瑚红到玫瑰红 |
| 坚毅 | `#D99887` | `#BC7C86` | 暖陶色到灰玫瑰色 |
| 背水 | `#FF8F91` | `#E36483` | 保留较鲜明的红色 |
| 穿刺 | `#71C9D8` | `#ACDFEE` | 青蓝到浅冰蓝，收敛明暗跨度 |

中英文使用相同端点，其余 38 个词缀保持既有配色。资源生成器是颜色来源；普通物品名称、提示框和重铸台共用同一解析器。只调整静态 RGB，不新增动画、着色器或绘制通道。两条版本线共用屏幕内的文本排版缓存，状态不变时复用解析好的渐变。

开发预览从第一次放入装备起就使用现行配色，不再自动先放旧色样品再替换。26.2 已检查同一把三叉戟首次显示、等待、悬停、移开和资源重载后的颜色，见 [验证记录](verification.md)。

## 背景纹理

纹理：[lunar_backdrop.png](../common/src/main/resources/assets/luna_reforged/textures/gui/lunar_backdrop.png)。原始尺寸为 1448 × 1086，游戏中缩放到 304 × 224 GUI 像素，随模组资源一起打包。

月牙和星光位于右上角，边缘保留细银色纹饰。中央与下方使用低对比度的暗色纹理，避免干扰物品槽、效果说明和费用文字。

## 参考与实现

- [Reforges 默认词缀](https://github.com/Auxilor/Reforges/tree/8ee14ce9c6d979d5fa5a7e71a6e2e4df964d2d4e)：保留渐变名称与数值在前的彩色说明格式，部分端点从 0.5.0 起按上述深色界面配色调整。所有内置词缀现在由同一个描述器读取实际机制参数，避免两套文字各自漂移。
- [Apotheosis 的生命汲取说明](https://github.com/Shadows-of-Fire/Apotheosis/blob/ae0ef786b20dc2b3b504f20595844181c2a02be9/src/main/resources/assets/apotheosis/patchouli_books/apoth_chronicle/en_us/entries/adventure/attributes/life_steal.json)及 [MobEffectAffix](https://github.com/Shadows-of-Fire/Apotheosis/blob/ae0ef786b20dc2b3b504f20595844181c2a02be9/src/main/java/dev/shadowsoffire/apotheosis/affix/effect/MobEffectAffix.java)：参考伤害收益、目标与状态持续时间明确分开的做法。本项目独立实现较小的一组效果，额外限制每次治疗与共用冷却；没有复制其代码、美术或数据文件。
- [owo-lib 的粒子与文本功能](https://github.com/wisp-forest/owo-lib)：参考一次事件组合出短暂反馈的思路。当前实现使用原版方块事件与粒子类型，没有增加 GUI 或粒子库依赖。

重铸成功后，一个方块事件携带 0–4 的效果类型编号，客户端本地生成最多 32 个粒子；不把 RGB 整数塞进只传一个字节的参数。烬火用火星、霜凝用雪点、汲月用心形反馈，击杀/挖掘经验类使用绿色星点。命中特效只在伤害接受且生命或吸收生命确实减少后发送，服从同一个攻击者的冷却。没有每 tick 扫描世界、粒子实体或常驻方块实体。

GUI 动画只在收到服务端交易回执后显示成功。物品槽、键盘聚焦、按钮确认、提示框仍使用原生容器组件。实际截图与验证范围见 [验证说明](verification.md)。

# 自定义词缀（0.5.0）

可以自行写配置，不必重新编译模组。但它与插件版 **不是同一种格式或效果引擎**。插件版的 YAML、libreforge 的 `effects / triggers / conditions` 不能直接放进来。

## 创建一个词缀

1. 启动一次安装了 0.5.0 的服务端，或进入一次单人世界。
2. 打开实例的 `config/luna-reforged/reforges/`。
3. 复制自动生成的 `_example.json`，命名为 `starforged.json`，内容如下。示例文件本身不会被加载。
4. 重启服务端；单人游戏退出世界再进入。右槽留空，普通随机重铸就有机会得到它。

```json
{
  "id": "starforged",
  "name": "<gradient:#C8B6FF>星铸</gradient:#7DE2FC>",
  "description": ["&a+6% &f近战伤害", "&a+5% &f下落攻击伤害"],
  "targets": ["melee"],
  "damage": 1.06,
  "critical": 1.05
}
```

文件名必须等于 `id + .json`。ID 以小写字母开头，其余仅限小写字母、数字、下划线，最长 48 字符。最多 256 个文件；仅加载这个目录下不以 `_` 开头的 `.json` 文件，不扫描子目录。

新增 ID 不能覆盖 44 个内置词缀。自定义词缀参与普通等概率抽取，仍排除当前词缀。当前不支持由 JSON 动态注册新的重铸石或配方。

## 字段

未填写的效果字段使用表中默认值。名称和说明支持上游 eco 的 `<gradient:#RRGGBB>文字</gradient:#RRGGBB>`，以及 `&0`–`&f`、`&k`–`&o`、`&r`、`&#RRGGBB`；`§` 形式也可读取。渐变按 Unicode 字符插值，颜色码不参与插值。它不是完整 MiniMessage 解释器，不执行命令、占位符、点击事件或悬浮事件。省略 `description` 或设为空数组时按数值自动生成说明；手写说明按原文显示，请保持文字与数值一致。整个配置和补齐默认值后的物品快照都必须在 4096 字符内。

| 字段 | 含义 | 默认值 / 范围 |
|---|---|---|
| `id` | 文件和存档标识 | 必填 |
| `name` | 支持渐变的显示名称 | 自定义配置必填；包括格式标记在内最多 512 字符 |
| `description` | 支持颜色的说明字符串数组 | 最多 4 行，每行包括格式标记在内最多 512 字符 |
| `targets` | 适用装备类型数组 | 必填且非空 |
| `damage` | 武器伤害乘数 | 1.0；0.1–5.0 |
| `critical` | 玩家近战且向下速度 `< -0.1` 时的额外伤害乘数 | 1.0；0.1–5.0 |
| `incoming` | 受到伤害的乘数，护甲生效 | 1.0；0–3.0 |
| `incomingScope` | 护甲事件范围；`environment` 排除实体来源 | `all`；`all` / `environment` / `fall` / `fire` / `projectile` |
| `speed` | 装备/持有期间的移速比例增量 | 0；-0.5–1.0 |
| `attackSpeed` | 攻速比例增量 | 0；-0.5–1.0 |
| `miningSpeed` | 挖掘速度比例增量 | 0；-0.5–1.0 |
| `knockback` | 攻击击退的固定增量 | 0；-1.0–2.0 |
| `knockbackMultiplier` | 攻击击退属性的乘数 | 1.0；0–3.0 |
| `knockbackResistance` | 击退抗性的固定增量 | 0；0–0.5 |
| `killXp` | 击杀生物时奖励的经验点 | 0；0–100 整数 |
| `miningXp` | 挖掘方块时奖励的经验点 | 0；0–20 整数 |
| `condition` | 事件效果条件 | `always` |
| `chance` | 每个事件效果的触发概率 | 1.0；0–1 |
| `burnSeconds` | 有效命中后点燃的秒数 | 0；0–5 整数 |
| `slowTicks` | 有效命中后缓慢 I 的持续 tick | 0；0–100 整数 |
| `lifeSteal` | 有效伤害转为治疗的比例，每次最多 1 点生命 | 0；0–0.10 |
| `procCooldown` | 点燃、缓慢、汲取按攻击者共用的冷却 tick | 20；20–200 整数 |

`targets` 可用 `melee`、`axe`、`bow`、`trident`、`armor`、`pickaxe`。斧同时属于 `melee` 和 `axe`；弓/弩的伤害效果用于箭矢，三叉戟用于投掷伤害，不能通过拿弓近战来触发远程增益。其他模组装备需要有对应原版标签/装备槽；自定义投射物家族可能需要代码适配。

`condition` 可用：

- `always`：始终。
- `air` / `water`：效果触发时，使用者在空中 / 水中。
- `night`：有天空光照的维度中，一天的第 13000–22999 tick；不以雷雨造成的昏暗代替夜间。
- `low_health`：生命不高于最大生命的 40%。
- `full_health`：生命不低于最大生命的 90%。

条件及概率控制伤害、下落攻击、护甲减伤和经验奖励。攻击/击杀检查攻击者，护甲检查受击者，挖掘检查挖掘者。同一个词缀在一次伤害事件中共用一次判定，普通伤害与下落增益一起生效；击杀、挖掘等后续事件各自判定。此紧凑字段模型不能表达 libreforge 为每个效果配置独立概率的全部组合。

`speed`、`attackSpeed`、`miningSpeed`、`knockback`、`knockbackMultiplier` 和 `knockbackResistance` 是原生装备属性，**不受 `condition` / `chance` 控制**，只随正确装备槽生效。护甲属性作用于其穿戴槽，其他装备作用于主副手。多件护甲的伤害乘数相乘；允许处理摔落等绕过普通护甲的伤害，但始终排除虚空和强制击杀。原版四种护甲词缀为 `environment`；自定义词缀默认 `all`。

`critical` 沿用当前上游对“下落攻击”的判断，与 Minecraft 原版暴击标志并不相同；速度刚好为 `-0.1` 时不会生效。`knockbackMultiplier` 作用于原生攻击击退属性，该属性为零时仅改变乘数不会凭空产生击退。

## 同步和修改行为

配置仅需放在服务端。成功重铸时，自定义词缀的完整参数、名称和说明会作为原生物品组件保存并同步，因此客户端无需复制配置文件，也能显示自定义词缀。

**自定义物品保存的是重铸时的参数快照。** 修改或删除 JSON 后，已有装备保持当时的数值，新生成的词缀使用新配置。这与插件版的集中 ID 查询/重载模式不同。若想让旧装备采用新参数，需要先换成别的词缀，再重新获得该词缀。全局触发语义仍随模组版本更新，例如 0.3.0 对 `critical` 的下落判定。内置词缀沿用原有 ID；旧版物品装备时自动刷新本模组属性，不扣费、不增加次数。0.3.0 自定义快照新增字段，不提供回退到 0.2.0 的存档保证。

所有文件先完整校验，再替换服务端候选表；字段拼错、类型错误、数值越界或 ID 冲突会报告具体文件并拒绝加载，避免静默接受无效配置。没有 `/reload` 热更新或 `/reforges` 插件命令。

## 与插件版对照

| 项目 | 原插件 | 辉月重铸 0.5.0 |
|---|---|---|
| 格式 | 每个词缀一个 YAML | 每个词缀一个 JSON |
| 基本思路 | 名称、说明、目标、效果 | 相同 |
| 颜色 | eco 文本和各类占位符 | eco 渐变、常见颜色/格式码，无占位符 |
| 效果 | libreforge 效果/触发器/条件系统 | 上表列出的原生效果字段 |
| 重载 | `/reforges reload` | 重启服务端 / 重进单人世界 |
| 自定义石头 | YAML 中配置物品、配方等 | 三种固定石头；自定义 JSON 不注册物品 |
| 经济 | 插件价格提供器等 | 经验等级，可选定向重铸石 |
| 第三方联动 | Bukkit、eco、PlaceholderAPI 等 | 需要专门的原生模组适配 |

参考：[上游自定义词缀说明](https://github.com/Auxilor/Reforges/blob/master/ecohub/reforges/how-to-make-a-custom-reforge.md)。0.4.0 已提供有上限的生命汲取、点燃、缓慢和共用冷却字段。连锁闪电、任意技能或命令触发仍需要新的原生实现，不能直接填写 libreforge 效果名。

## 0.4.0 的自动说明与触发条件

省略 `description` 或设为空数组，提示框和 GUI 会按实际字段生成彩色分行说明。显式写入的自定义说明按原文保留，服主需自行保证描述与效果一致。旧版本自定义物品仍保留其说明快照。

新增 `condition` 值：`day`（有天空的维度且不在本模组夜间范围）、`rain`（攻击者位置正在淋雨）、`sprinting`（疾跑）、`distant`（命中时攻击者与目标距离至少 12 格）、`wounded_target`（命中前目标生命不高于 30%）。后两种需要一个被命中的目标，适合武器；不用于挖掘或被动属性。

`burnSeconds`、`slowTicks`、`lifeSteal` 在命中被接受、生命或吸收生命实际减少之后处理。被拒绝的命中不消耗冷却；跨目标、换手及换武器不能绕过同一攻击者的冷却。伤害倍率和命中特效各自检查概率，属于独立事件阶段。被动属性仍在装备或手持时持续生效，不受 `condition` 和 `chance` 控制。新增字段随自定义物品快照保存；升级前备份存档，不承诺将新快照降级到旧版读取。

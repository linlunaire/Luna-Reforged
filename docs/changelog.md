# 0.5.1 · 2026-10-17

- 1.21.1 的 LunaCore 源码、构建和发行迁回 LunaCore 仓库，与 26.2 一起维护。
- 两个游戏版本都通过 Gradle 依赖 LunaCore 0.4.1，开发启动自动加载对应前置。
- 辉月发行包只提供自身四个 JAR、完整源码和文档；安装时另从 LunaCore 发行页下载前置。
- 本次仅调整依赖与发行结构，玩法和渲染保持 0.5.0 的行为。

# 0.5.0 · 2026-10-11

- 前置统一为 LunaCore 0.4.0，内部 ID、JVM 包名和 Maven 坐标使用 `lunacore`；1.21.1 兼容前置同步迁移。
- 战斗回调直接处理双手与投射物词缀，移除临时武器列表和重复资格解析；菜单与战斗资格判断不再构建目标集合。
- 两条版本线共用屏幕内的文本排版缓存，稳定帧复用渐变名称、说明、裁剪和提示。物品快照、价格、状态、语言及成功回执变化时刷新。
- 修复配置失败时价格、词缀开关与候选表可能不一致的问题；拒绝字符串伪装的数字配置。
- 同步核心的资源计量失败清理与异步队列改进，避免回调持有发布锁，保留容量限制和恰好一次清理。
- 潮汐改为海青到水蓝；同时提亮引力、坚毅、强韧、背水并收敛穿刺的明暗跨度，改善深色面板和两字中文名称的可读性。中英文配色同步。
- 补充 26.2 原生 Vulkan 的双加载器实测、实际后端断言、资源重载及固定鼠标的渐变检查；说明 NeoForge 26.2 早期加载窗口的配置要求。

配套升级两个 JAR，并移除旧核心。新版本验证范围见 [验证记录](verification.md)。

# 构建与主页维护 · 2026-10-01

- 资源生成、发行 JAR 检查、源码归档和安装包打包工具改为 Kotlin，通过现有 Gradle Wrapper 运行。
- 剩余九个 Java 接口与混入类转换为 Kotlin；Gradle 构建脚本改用 Kotlin DSL，保留两条版本线的工具链。
- 1.21.1 Fabric 由 Loom 直接映射 Kotlin 混入的目标名称，发行验包增加注解目标和 Kotlin 元数据检查。
- 主页采用居中标识、徽章、截图和文档导航；安装、配置及构建说明移至独立文档。
- 重新清理并构建四个组合，完成服务端和真实客户端联机回归；生成的 36 个 JSON 内容保持一致。

# 0.4.0 · 2026-09-30

- 所有内置词缀从实际参数生成彩色分行描述，修复扩展词缀数值后置、颜色缺失的问题；GUI 与物品提示共用描述。
- 新增 16 个词缀，合计 44 个。加入有效命中后的点燃、缓慢 I、生命汲取和共用冷却，以及天气、疾跑、距离、目标生命条件与细分伤害减免。
- 重做月色主题 GUI：左侧操作，右侧预览当前词缀或重铸石效果；完整描述可悬停查看，保留原生键盘交互。
- 增加生成的月色背景纹理。重铸粒子按效果类型变化，每次最多 32 个；命中特效只在服务端确认有效伤害后发送。
- 前置更新为 LunaCore 0.3.0，1.21.1 兼容构建同步为 0.3.0+mc1.21.1。安装包附前置完整源码。

# 0.3.0 · 2026-09-30

- 还原上游 16 个默认词缀的渐变端点；本地化物品名称前缀、菜单名称、石头名称和分行彩色说明。新增未重铸提示，长菜单文字在裁剪后保留颜色。
- 原生文本解析器支持 eco 渐变、常见颜色和格式码、十六进制颜色；自定义 JSON 也可使用。按 Unicode 字符插值，不把格式码当成可见文字。
- 前缀只参与显示，保留原始物品名称。适配客户端铁砧输入与服务端费用判断，单独覆盖 26.2 NeoForge 的计算分支，防止重复前缀和无故改名收费。
- 普通重铸不再要求或消耗紫水晶，勘探加入随机池；普通抽取继续排除当前词缀。定向石允许再次施加同一词缀。
- 新默认增长率 1.15，灵动石独立默认价 40 级，其余石头固定基础价；保留经验经济和普通重铸 30 级上限，已有价格配置不覆盖。
- 灵动/丰饶配方对齐上游的原版材料回退配方；勘探石作为既有扩展保留。12 个原生扩展词缀可从随机池关闭。
- 强韧/轻盈改用百分比攻击击退属性；近战与被动属性支持副手；默认护甲按当前上游触发器只作用于环境伤害；引力/灵动以向下速度判断额外伤害。相应说明不再误称原版暴击标志或所有来源减伤。
- 旧装备在装备时刷新本模组属性，保留外部修饰器、名称、耐久和已重铸次数。
- 增加渐变端点、Unicode、铁砧改名、旧装备迁移、原版抽取池开关、空槽重铸、重复石头、下落阈值和环境伤害的检查；客户端夹具覆盖两种重铸交易、自定义渐变、真实铁砧改名和截图。

范围、来源与保留差异见 [对齐说明](compatibility.md)，测试结果见 [验证记录](verification.md)。

# 0.2.0 · 2026-09-30

- 重铸台改为月牙环、分层晶核、四角支架和符文台面，加入轻量待机星点及成功星环粒子、附魔音效；台体碰撞、选中轮廓和空隙遮挡分别处理。
- GUI 使用共用动画状态和缓存像素几何，收到服务端成功序号后才显示成功闪光；等待回执时短暂禁用按钮，超时恢复。长词缀名称适配可用宽度。
- 增加 12 个词缀，合计 28 个：破阵、决斗、月华、背水、凝神、磐石、疾行、庇护、共鸣、掘进、博识、均衡。包括条件攻击/减伤、击退抗性、挖掘速度等效果。
- 增加 `config/luna-reforged/reforges/*.json` 自定义词缀和自动生成的示例，严格校验 ID、类型、数值和字段；全部成功后一次替换候选表。
- 自定义词缀通过物品组件保存完整参数并同步显示，不依赖客户端本地配置。已有自定义装备保持生成时的参数，重启后的新抽取采用新定义。
- 复用装备标签，缓存菜单候选列表和价格；物品变化及提交时重新校验，避免每 tick 重新筛选整个词缀表。战斗不解析 JSON。
- 修正远程词缀可因拿弓近战而误触发的问题；新增参数、快照、条件效果、属性替换和服务端成功序号的回归检查。
- 修复 26.2 NeoForge 打开菜单时扩展工厂的空数据包触发 Kotlin 非空检查、导致客户端断线的问题；两版 NeoForge 统一使用无需附加数据的普通菜单工厂。
- 预览测试扩展到四种客户端组合，并隔离客户端和服务端目录，避免 Windows 锁住日志与 Fabric 处理缓存。
- 提供 26.2 / 1.21.1、Fabric / NeoForge 四个独立构建。

确切验证结果与尚未覆盖的场景见 [验证记录](verification.md)。
